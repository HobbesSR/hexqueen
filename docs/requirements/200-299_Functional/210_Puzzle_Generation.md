# 210: Puzzle Generation

## 211: Puzzle Parameters
* Puzzles are generated based on a `radius` parameter determining size/queen count

## 212: Puzzle Validity
* Generated puzzles must be valid HexQueen configurations

## 213: Unique Solution
* All generated puzzles must have exactly one valid solution

## 214: Logical Solvability
* Puzzles must be solvable using logical inferences only
