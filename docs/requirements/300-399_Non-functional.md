# 300-399: Non-functional Requirements

## 310: Puzzle Quality

*   **311: Solvability:**
    *   Puzzles generated must be solvable.
*   **312: Uniqueness:**
    *   Puzzles generated must have a unique solution.
*   **313: Logical Solvability:**
    *   Puzzles should be solvable using logical deduction, without requiring guessing or brute-force methods.
