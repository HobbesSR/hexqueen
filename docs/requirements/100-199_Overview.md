# 100-199: Overview

## 100: Project Goal

The HexQueen project is intended to generate a new kind of logic puzzle, similar to the Queens puzzle, with features for puzzle generation, visualization, and standard output for a puzzle app.

## 110: Puzzle Description

HexQueen puzzles are logic puzzles designed to be valid, have unique solutions, and be solvable through logical inferences, without requiring brute-force methods.

## 120: Intended Users

The primary users are the administrator of the upcoming puzzle application and open-source users interested in generating their own puzzles.
